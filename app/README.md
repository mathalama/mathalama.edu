# MathalamaEdu — Frontend Client

Добро пожаловать во фронтенд-клиент **MathalamaEdu** — современной событийно-ориентированной платформы управления обучением (LMS) с высокой степенью геймификации, построенной по принципу **Bento UI** и **Frontend-First** архитектуры.

Этот клиент разработан с использованием передовых технологий веб-разработки для обеспечения молниеносного интерфейса, бесшовных переходов и максимального вовлечения студентов в образовательный процесс.

---

## Технологический стек

*   **Фреймворк**: [Next.js 16 (App Router)](https://nextjs.org/) — серверный и клиентский рендеринг, оптимизированная маршрутизация.
*   **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) — усовершенствованная система дизайн-токенов в `@theme` и кастомных CSS-переменных.
*   **Анимации**: [Framer Motion](https://www.framer.com/motion/) — плавные переходы между страницами, микро-интеракции и плавное появление элементов Bento-сетки.
*   **Стейт-менеджер**: [Zustand](https://github.com/pmndrs/zustand) — легковесное, реактивное и производительное управление глобальным состоянием с фасадом для интеграции API.
*   **Иконки**: [Lucide React](https://lucide.dev/) — чистые векторные иконки.
*   **База данных (Mock)**: Локальное хранилище (`localStorage`) с симуляцией сетевых задержек для реалистичного UX.

## Основные фичи и архитектурные решения

### 1. Bento UI интерфейс и Геймификация
Интерфейс построен в виде интерактивной Bento-сетки с динамическими виджетами и плавными Framer Motion переходами:
- **SmartResumeCard**: Панель быстрого продолжения последнего активного урока с отображением прогресса.
- **ActiveCoursesCard**: Список активных курсов с индикаторами прохождения.
- **DeadlinesList**: Список ближайших дедлайнов по тестированию и домашним заданиям.
- **ProfileCard** (на странице профиля): Круговой SVG-индикатор уровня с расчетом прогресса XP.
- **ActivityHeatmap** (на странице аналитики): GitHub-style календарная сетка активности за последние 24 недели с логированием XP.

### 2. Event-Driven Конвейер Урока (Content Dripping)
Последовательное прохождение уроков:
1.  **Видеоплеер (VideoPlayer)**: Watch tracker с автосохранением прогресса и конспектом с таймкодами.
2.  **Тестирование (Inline-тест)**: Проверка знаний по теме с мгновенной валидацией ответов и подсветкой результатов.
3.  **Домашнее задание (PDF Submission)**: Загрузка файлов с симуляцией прогресс-бара антивирусной проверки.
*Контент-дриппинг блокирует последующие уроки, пока текущий не сдан.*

### 3. Тёмная тема (Dark Mode)
Нативная поддержка темного оформления через `[data-theme="dark"]` и CSS-переменные с сохранением выбора пользователя в локальной базе данных.

## Структура страниц (10 уникальных маршрутов)

MathalamaEdu имеет разветвленную структуру страниц, создающую ощущение зрелого и наполненного продукта:

| Маршрут | Описание страницы |
| :--- | :--- |
| `/` | **Точка входа** — Автоматический клиентский редирект на дашборд или страницу авторизации. |
| `/login` | **Вход** — Защищенная форма авторизации с демонстрационными credentials (`student@example.com` / `password`). |
| `/dashboard` | **Дашборд** — Bento-панель с карточками продолжения обучения, списком активных курсов и ближайшими дедлайнами. |
| `/courses` | **Каталог Курсов** — Прогресс-бар курса и список модулей с логикой dripping-доступа. |
| `/courses/[id]/lessons/[id]` | **Страница Урока** — Полноэкранный плеер лекции, markdown-теория, интерактивный тест и отправка ДЗ. |
| `/analytics` | **Аналитика** — Статистика успеваемости и календарь активности (Activity Heatmap). |
| `/notifications` | **Уведомления** — Лента системных оповещений (проверка ДЗ, достижения) с отметками "прочитано". |
| `/certificates` | **Сертификаты** — Визуальная грамота с QR-кодом верификации и поддержкой печати. |
| `/profile` | **Профиль** — Прогресс XP, форма редактирования личных данных и GDPR-экспорт/удаление аккаунта. |
| `/settings` | **Настройки** — Переключатель темы (Dark/Light), смена языков (RU/KZ/EN), управление уведомлениями и смена пароля. |

## Быстрый старт

### Требования
*   [Node.js](https://nodejs.org/) v18.0.0 или выше
*   [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/)

### Установка зависимостей
Перейдите в директорию frontend-приложения и установите пакеты:
```bash
cd app
npm install
```

### Запуск в режиме разработки
Запустите локальный сервер разработки:
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена
Скомпилируйте оптимизированный билд приложения:
```bash
npm run build
```

## Интеграция с Go-монолитом в будущем

Фронтенд спроектирован по паттерну "чистого интерфейса" (facade). Стейт-менеджер `src/store/useLmsStore.ts` полностью инкапсулирует логику работы с данными:
1. В режиме **Mock Mode** данные читаются/пишутся в `localStorage` через хелперы в `src/mocks/db.ts`.
2. При переходе на **Production** достаточно заменить реализацию методов Zustand-стора на реальные вызовы HTTP/gRPC API. Модели данных (Dripping, SM2, Leaderboard) спроектированы так, чтобы в точности соответствовать DTO структурам Go-монолита.
