# MathalamaEdu — Frontend Client

Добро пожаловать во фронтенд-клиент **MathalamaEdu** — современной событийно-ориентированной платформы управления обучением (LMS) с высокой степенью геймификации, построенной по принципу **Bento UI** и **Frontend-First** архитектуры.

Этот клиент разработан с использованием передовых технологий веб-разработки для обеспечения молниеносного интерфейса, бесшовных переходов и максимального вовлечения студентов в образовательный процесс.

---

## Технологический стек

*   **Фреймворк**: [Next.js 16 (App Router)](https://nextjs.org/) — серверный и клиентский рендеринг, оптимизированная маршрутизация.
*   **Стилизация**: [Tailwind CSS v4](https://tailwindcss.com/) — усовершенствованная система дизайн-токенов в `@theme` и кастомных CSS-переменных.
*   **Анимации**: [Framer Motion](https://www.framer.com/motion/) — плавные переходы между страницами, микро-интеракции и плавное появление элементов Bento-сетки.
*   **Стейт-менеджер**: [Zustand](https://github.com/pmndrs/zustand) — легковесное, реактивное и производительное управление глобальным состоянием с фасадом для интеграции API.
*   **Иконки**: [Lucide React](https://lucide.dev/) — чистые векторные иконки.
*   **База данных (Mock)**: Локальное хранилище (`localStorage`) с симуляцией задержек сети,spaced-repetition SuperMemo-2 и PvP-соревнований.

## Основные фичи и архитектурные решения

### 1. Bento UI интерфейс и Геймификация
Интерфейс построен в виде интерактивной Bento-сетки с динамическими виджетами:
- **ProfileCard**: Круговой индикатор уровня, прогресс XP и витрина разблокированных бейджей.
- **Leaderboard**: Таблица лидеров группы (потока) и глобальный топ с интерактивным просмотром профилей однокурсников.
- **ActivityHeatmap**: GitHub-style сетка активности за последние 24 недели с логированием XP.
- **FriendsList**: Список друзей в реальном времени с индикаторами статуса присутствия ("Смотрит видео", "Проходит тест") и чатом.

### 2. Event-Driven Конвейер Урока (Content Dripping)
Последовательное прохождение уроков:
1.  **Видеоплеер (VideoPlayer)**: Watch tracker с автосохранением прогресса в Redis (мок через 15 секунд) и конспектом с таймкодами (быстрая заметка по `Cmd + K`).
2.  **Тестирование (Inline-тест)**: Проверка знаний по теме с мгновенной валидацией и подсветкой ошибок.
3.  **Домашнее задание (PDF Submission)**: Загрузка файлов с прогресс-баром и антивирусным сканированием (мок).
*Контент-дриппинг блокирует последующие уроки, пока текущий не сдан и не проверен.*

### 3. Алгоритм интервальных повторений SuperMemo-2 (SM2)
Раздел **Spaced Repetition** интегрирует научный подход к запоминанию информации:
- Карточки повторения рассчитывают коэффициент легкости (Easiness Factor), интервал повторений и дату следующего обзора по ответам пользователя (от 0 до 5).

### 4. PvP Арена Баттлов (BattleArena)
Студенты могут устраивать состязания в реальном времени:
- Симуляция соперников на основе их XP.
- Начисление очков за правильность и скорость ответа (Speed Bonus).
- Пьедестал почета с награждением XP.

### 5. Тёмная тема (Dark Mode)
Нативная поддержка темного оформления через `[data-theme="dark"]` и CSS-переменные с сохранением выбора пользователя в локальной базе данных.

## Структура страниц (11 уникальных маршрутов)

MathalamaEdu имеет разветвленную структуру страниц, создающую ощущение зрелого и наполненного продукта:

| Маршрут | Описание страницы |
| :--- | :--- |
| `/` | **Landing Page** — Презентационная страница с фичами, статистикой и призывом к действию. |
| `/login` | **Вход** — Защищенная форма авторизации с троттлингом (Rate-Limit 429 при перегрузке). |
| `/dashboard` | **Дашборд** — Bento-сетка с ключевыми геймифицированными виджетами, ареной и карточками повторений. |
| `/courses` | **Каталог Курсов** — Прогресс-бар курса и список модулей с логикой dripping-доступа. |
| `/courses/[id]/lessons/[id]` | **Страница Урока** — Полноэкранный плеер, markdown-теория, интерактивный тест, отправка ДЗ и навигация. |
| `/analytics` | **Аналитика** — Столбчатый график набора XP за неделю, воронка успеваемости и когортный анализ. |
| `/notifications` | **Уведомления** — Лента оповещений (проверка ДЗ, баттлы, обгон в рейтинге) с отметками "прочитано". |
| `/certificates` | **Сертификаты** — Визуальная грамота с QR-кодом верификации, доступная после закрытия курса на 100%. |
| `/profile` | **Профиль** — Данные студента, GDPR-запросы на экспорт данных и двухфазное удаление аккаунта. |
| `/settings` | **Настройки** — Переключатель темы (Dark/Light), смена языков (RU/KZ/EN), привязка Telegram по QR и смена пароля. |

## Быстрый старт

### Требования
*   [Node.js](https://nodejs.org/) v18.0.0 или выше
*   [npm](https://www.npmjs.com/) или [yarn](https://yarnpkg.com/)

### Установка зависимостей
Перейдите в директорию frontend-приложения и установите пакеты:
```bash
cd app
npm install
```

### Запуск в режиме разработки
Запустите локальный сервер разработки:
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена
Скомпилируйте оптимизированный билд приложения:
```bash
npm run build
```

## Интеграция с Go-монолитом в будущем

Фронтенд спроектирован по паттерну "чистого интерфейса" (facade). Стейт-менеджер `src/store/useLmsStore.ts` полностью инкапсулирует логику работы с данными:
1. В режиме **Mock Mode** данные читаются/пишутся в `localStorage` через хелперы в `src/mocks/db.ts`.
2. При переходе на **Production** достаточно заменить реализацию методов Zustand-стора на реальные вызовы HTTP/gRPC API. Модели данных (Dripping, SM2, Leaderboard) спроектированы так, чтобы в точности соответствовать DTO структурам Go-монолита.
