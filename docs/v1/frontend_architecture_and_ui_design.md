# Архитектура Фронтенда MathalamaEdu (v1)

Этот документ описывает спецификацию фронтенд-приложения первой версии (v1) образовательной платформы **MathalamaEdu**. 

Поскольку проект построен по принципу **Frontend-First / Serverless Mock**, всё приложение функционирует автономно в браузере. Данные считываются и записываются в `localStorage` через стейт-менеджер **Zustand**.

---

## 1. Технологический стек фронтенда

*   **Фреймворк:** Next.js 16.2.6 (App Router) + React 19.2.4
*   **Стейт-менеджер:** Zustand 5.0.13 (глобальное состояние, имитация методов API бэкенда)
*   **Стилизация:** Tailwind CSS 4.0.0 + ванильный CSS-переменные (дизайн-система тем оформления)
*   **Анимации:** Framer Motion 12.40.0 (плавные каскадные Bento-карточки, модальные окна, слайдер активного меню)
*   **Иконки:** Lucide React 1.16.0

---

## 2. Глобальное состояние и хранение данных (Zustand + LocalStorage)

Все данные приложения находятся в Zustand-хранилище [useLmsStore.ts](file:///c:/Users/Admin/Desktop/mathalama.edu/app/src/store/useLmsStore.ts). 

При первой загрузке данные инициализируются из `localStorage` (если пусто — база заполняется стандартными значениями из [db.ts](file:///c:/Users/Admin/Desktop/mathalama.edu/app/src/mocks/db.ts)).

### Схема взаимодействия:
```
[React-компоненты] ---> [Селекторы / Actions Zustand]
                             |
                             +---> [Мутация состояния в памяти React]
                             |
                             +---> [Запись в HTML5 LocalStorage (JSON-строка)]
```

Основные мутации (Actions):
*   `login(email, password)`: проверяет credentials, генерирует фейковый JWT, записывает токен в хранилище.
*   `logout()`: стирает сессию и очищает состояние.
*   `completeVideo(lessonId)`: отмечает просмотр лекции, начисляет `+25 XP` и сохраняет активность в `heatmap`.
*   `passQuiz(lessonId, score)`: записывает результат прохождения теста и отмечает его как сданный.
*   `submitPdf(lessonId, fileName)`: отправляет PDF на симуляцию антивирусного сканирования и запускает таймер автоматического апрува (6 секунд) от Telegram-бота куратора.
*   `addVideoNote(lessonId, seconds, text)`: добавляет текстовую заметку с привязкой к таймкоду видео лекции (`+10 XP`).

## 3. Структура маршрутизации и дизайн макетов (Next.js App Router)

### 3.1. Структура директорий `app/src/app`
```
app/src/app/
├── (dashboard)/             # Группа маршрутов личного кабинета (с общим макетом)
│   ├── layout.tsx           # Общий макет: оборачивает страницы в DashboardLayout
│   ├── analytics/           # Страница статистики и тепловой карты активности
│   ├── certificates/        # Просмотр и скачивание выданных сертификатов
│   ├── courses/             # Каталог курсов, модулей и страниц уроков
│   ├── dashboard/           # Bento-панель управления (продолжить обучение, дедлайны)
│   ├── notifications/       # Список системных оповещений
│   ├── profile/             # Профиль студента и GDPR-стирание данных
│   └── settings/            # Настройки (тема, язык, каналы уведомлений)
├── login/                   # Страница авторизации (без сайдбара)
├── layout.tsx               # Глобальный корневой макет (ThemeInitializer, ToastContainer)
└── page.tsx                 # Точка входа (клиентский редирект)
```

### 3.2. Персистентный макет `DashboardLayout`
Благодаря переносу папок кабинета внутрь группы `(dashboard)/` и созданию единого [layout.tsx](file:///c:/Users/Admin/Desktop/mathalama.edu/app/src/app/(dashboard)/layout.tsx), компонент сайдбара и шапки **никогда не пересоздается** при навигации по разделам.
*   Это исключает повторный запуск лоадера `isMounted` при переходах.
*   Сохраняет состояние проигрывателей и уведомлений.
*   Позволяет фоновому индикатору активного пункта меню (`layoutId="sidebarActiveBg"` из Framer Motion) плавно перетекать от одной кнопки меню к другой.

## 4. Интерактивные компоненты Bento UI

### 4.1. Видеоплеер (VideoPlayer)
Имитирует воспроизведение лекций через провайдеры Kinoscope и Vimeo.
*   Контролирует прогресс просмотра.
*   Позволяет ставить метки времени для быстрого создания заметок.
*   По завершении видео автоматически вызывает action `completeVideo` в Zustand.

### 4.2. Календарь активности (ActivityHeatmap)
Встраивается на страницу аналитики.
*   Группирует массив `heatmap` из хранилища по колонкам недель (по 7 дней в каждой).
*   Окрашивает дни в оттенки изумрудного в зависимости от заработанного XP.
*   Использует переменные темы оформления (`var(--heatmap-empty)`, `var(--heatmap-low)`, `var(--heatmap-high)`).

### 4.3. Карточка профиля (ProfileCard)
Считает уровень студента на основе формулы `XP / 1000`.
*   Рисует красивый SVG-прогресс-бар в форме круга, отображая остаток опыта до следующего уровня.

### 4.4. Премиальный Сертификат (CourseraCertificate)
Рендерит векторный SVG-сертификат об окончании курса.
*   Динамически подставляет имя студента, название курса, дату выдачи и сгенерированный проверочный код.
*   Имеет медиа-запрос `@media print` в [globals.css](file:///c:/Users/Admin/Desktop/mathalama.edu/app/src/app/globals.css) для чистой альбомной печати сертификата из модального окна на принтере.
